아래 기능을 구현하고, 이 문서의 디자인 시스템을 적용해줘.
다른 프로젝트나 이전 대화의 맥락 없이 이 지침만으로 디자인을 완성해줘.

[필수 구현 기술: p5.js]

- 인터랙티브 시각 요소와 그래픽은 반드시 p5.js로 구현해줘.
- p5.js 인스턴스 모드를 사용하고, setup()과 draw()의 역할이 코드에서 명확히 드러나게 작성해줘.
- setup()에서는 캔버스 생성과 초기 설정을, draw()에서는 화면 그리기와 애니메이션 갱신을 처리해줘.
- 2D 표현은 P2D, 3D 표현은 WEBGL을 기능에 맞게 선택해줘.
- Three.js 등 다른 그래픽 엔진으로 대체하거나, p5.js를 불러오기만 하고 실제 렌더링에는 사용하지 않는 구현은 하지 마.
- 일반 버튼, 입력창, 설명, 메뉴는 HTML/CSS로 구성하고 p5.js 캔버스와 연결해줘.
- 캔버스도 위 디자인 시스템의 색상, 글꼴, 간격, 모션 규칙을 따라줘.
- 화면 크기와 픽셀 밀도를 고려하고, 크기 변경 시 캔버스와 그래픽 배치를 함께 조정해줘.
- 정적인 화면은 noLoop()와 redraw()를 활용하고, 애니메이션이 필요한 경우에만 연속으로 그려줘.
- 애니메이션은 deltaTime을 고려해 기기별 속도 차이를 줄여줘.
- 캔버스의 마우스·터치 입력과 HTML 컨트롤의 포커스·스크롤이 충돌하지 않게 해줘.
- 완료 후 p5.js 버전, setup()과 draw()의 파일 위치, 실제 렌더링에 사용한 p5.js API를 알려줘.

[1. 디자인 방향]

따뜻한 회색 바탕에 부드러운 입체감이 있는, 차분하고 정돈된 인터페이스를 만들어줘.

- 핵심 인상: 따뜻함, 절제, 편안함, 정밀한 마감.
- 넓은 여백과 명확한 타이포그래피로 정보의 위계를 만들어줘.
- 밝은 종이색 표면, 얇은 테두리, 은은한 그라데이션과 그림자를 사용해줘.
- 버튼과 입력창은 손으로 누를 수 있을 듯한 얕은 두께감을 표현해줘.
- 장식보다 콘텐츠와 주요 행동이 먼저 보이게 해줘.
- 높은 채도의 넓은 배경, 네온 효과, 강한 광택, 과한 블러는 피해주세요.
- 모든 콘텐츠를 개별 카드로 감싸지 말고, 관련된 정보를 여백과 구분선으로 묶어줘.
- 기능의 성격에 맞게 화면 구조를 설계하되 아래 시각 규칙은 일관되게 적용해줘.

- 어두운 표면이 필요한 경우 color-band 계열을 사용해줘.
- 어두운 화면에서도 같은 모서리, 간격, 글꼴 규칙을 유지해줘.

- 기본 버튼은 밝은 표면, 얇은 테두리, 얕은 그림자로 표현해줘.

- 보조 행동은 테두리 버튼이나 텍스트 버튼으로 표현해줘.
- 같은 영역에서 주요 행동의 시각적 우선순위를 명확히 해줘.

입력창:
- 한 줄 입력 높이는 52px.
- 밝은 종이색 배경과 얕은 안쪽 그림자를 사용해줘.
- 라벨은 입력창 위에 14px로 표시해줘.
- placeholder가 라벨을 대신하지 않게 해줘.

선택 컨트롤:
- 선택지가 적으면 세그먼트 컨트롤을 활용해줘.
- 트랙은 약간 어두운 표면, 선택 항목은 밝고 살짝 떠 있는 표면으로 표현해줘.

- 태그와 배지는 작은 글씨와 얇은 테두리를 사용해줘.
- 정보용 태그가 버튼처럼 보이지 않게 상호작용 표현을 구분해줘.

아이콘:
- 단순한 선형 아이콘을 사용해줘.
- 기본 크기는 16~20px, 주요 아이콘은 22~24px.
- 선 두께는 약 1.8~2px로 통일해줘.
- 아이콘만 있는 버튼에는 접근성 이름을 제공해줘.

목록과 표:
- 공통 시작선, 일정한 행 간격, 얇은 구분선으로 정리해줘.
- 숫자는 오른쪽 정렬을 우선해줘.
- 모든 셀을 둥근 카드로 만들지 마.

모달과 보조 패널:
- 제목, 설명, 본문, 행동 영역을 명확하게 구분해줘.
- 닫기 버튼은 쉽게 찾을 수 있는 위치에 배치해줘.
- 긴 내용은 내부 또는 화면에서 자연스럽게 스크롤되게 해줘.
- 데스크톱 모달을 모바일에서 단순 축소하지 말고 전체 화면이나 하단 패널로 조정해줘.


[7. 인터랙션과 모션]

시간:
- 누름 반응: 120ms.
- 호버, 포커스, 일반 전환: 220ms.
- 큰 영역의 상태 전환: 420ms.

이징:
- 기본: cubic-bezier(0.16, 1, 0.3, 1).
- 양방향 전환: cubic-bezier(0.65, 0, 0.35, 1).

동작:
- 호버에서는 테두리나 배경을 은은하게 변경해줘.
- 누르면 translateY(1px) 정도의 작은 반응을 줘.
- 원형 아이콘 버튼은 눌렀을 때 scale(0.96) 정도를 사용할 수 있어요.
- 포커스는 2px 윤곽선과 2px 간격으로 명확하게 표시해줘.
- 비활성 상태는 대비를 낮추되 글자를 읽을 수 있게 해줘.
- 반복적인 튀는 애니메이션이나 불필요한 자동 움직임은 피해주세요.
- prefers-reduced-motion 설정을 존중해줘.


[8. 반응형과 접근성]

- 960px 이하에서는 복잡한 다단 구성을 단일 열로 정리해줘.
- 720px 이하에서는 모바일에 맞게 여백, 제목 크기, 행동 영역을 조정해줘.
- 작은 화면에서 주요 버튼은 필요하면 전체 너비로 배치해줘.
- 360px 너비에서도 콘텐츠가 잘리거나 불필요한 가로 스크롤이 생기지 않게 해줘.
- 긴 텍스트와 확대된 글꼴에서도 버튼과 패널이 깨지지 않게 해줘.
- 조작 영역은 최소 44px을 확보해줘.
- 일반 텍스트 대비는 최소 4.5:1을 목표로 해줘.
- 색상만으로 선택, 오류, 성공 상태를 전달하지 마.
- 키보드 탐색 순서와 포커스 표시를 확인해줘.
- 모달은 포커스 이동·복귀와 Escape 닫기를 지원해줘.

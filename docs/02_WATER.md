# 1. 문서 개요

## 1-1. 문서 목적

본 문서는 웹 테라피 프로젝트의 WATER THERAPY 모듈에 대한 기능, 디자인 방향, 화면 구성, 인터랙션 및 개발 요구사항을 정의한다.

프로젝트의 공통 디자인 시스템과 기술 개발 규칙은 반드시 **01. BASE DESIGN SYSTEM & DEVELOPMENT GUIDELINES**를 따른다.

본 문서는 WATER THERAPY 모듈에만 해당하는 개별 요구사항을 정의한다.

01 문서와 본 문서의 요구사항이 충돌하는 경우 다음 원칙을 따른다.

- 공통 디자인 토큰, 타이포그래피, 간격, 컴포넌트, 접근성: 01 문서 우선
- WATER THERAPY의 개별 기능과 자연환경 표현: 02 문서 우선
- p5.js 구현 방식 및 기술적 제약: 01 문서 우선
- 사운드, 테마, 인터랙션: 02 문서 우선

## 1-2. 프로젝트 목적

WATER THERAPY는 물과 자연의 소리를 활용하여 사용자가 일상에서 벗어나 잠시 휴식할 수 있도록 돕는 인터랙티브 웹 테라피 공간이다.

사용자는 세 가지 자연환경 중 원하는 분위기를 선택할 수 있다.

1. FOREST STREAM
2. FLOW
3. UNDERWATER

각 테마는 독립적인 자연환경과 사운드를 가지고 있으며, 테마를 변경하면 시각적 배경과 애니메이션도 함께 전환된다.

단순한 오디오 플레이어가 아니라 시각과 청각을 동시에 활용하는 몰입형 디지털 휴식 경험을 제공하는 것이 핵심이다.

**Core Concept**

Listen to water, feel the moment.

소리를 듣는 것만으로도 다른 자연 공간에 들어온 듯한 경험을 제공한다.

# 2. 기본 개발 환경

## 2-1. 기술 스택

01 문서에서 정의한 필수 기술을 사용한다.

- HTML5
- CSS3
- JavaScript ES6+
- p5.js
- p5.sound

**중요: 인터랙티브 그래픽 렌더링은 반드시 p5.js를 사용한다.**

- p5.js 인스턴스 모드 사용
- setup()에서 캔버스 생성 및 초기화
- draw()에서 그래픽 렌더링 및 애니메이션 갱신
- HTML/CSS로 일반 UI 구성
- p5.js 캔버스와 HTML UI 연결
- 다른 그래픽 엔진으로 대체하지 않음

세부 기술 구현 규칙은 01 문서를 따른다.

## 2-2. 기본 파일 구조

현재 프로젝트의 파일 구조를 먼저 확인한다.

독립적으로 개발하는 경우 다음 구조를 기본으로 사용한다.

```text
water-therapy/
│
├── index.html
├── style.css
├── sketch.js
│
└── assets/
    ├── sound/
    │   ├── forest.mp3
    │   ├── flow.mp3
    │   └── underwater.mp3
    │
    └── images/
```

**중요: 실제 오디오 파일 경로는 `assets/sound/`이다.**

`assets/sounds/`를 사용하지 않는다.

기존 프로젝트의 폴더 구조가 위와 다르다면 임의로 파일을 이동하거나 변경하지 말고 실제 경로에 맞게 연결한다.

실제 MP3 파일명은 프로젝트를 확인한 후 확정한다.

# 3. 주요 사용자 경험

사용자가 WATER THERAPY에 진입하면 메인 화면이 나타난다.

기본 사용자 흐름:

1. 사용자가 웹페이지에 진입한다.
2. 자연환경을 표현하는 기본 화면이 표시된다.
3. 사용자가 원하는 테마를 선택한다.
4. 선택한 테마에 맞춰 시각적 배경과 애니메이션이 전환된다.
5. 사용자가 재생 버튼을 누르면 해당 테마의 사운드가 재생된다.
6. 사용자는 재생 및 일시정지, 음량 조절을 할 수 있다.
7. FLOW에서는 화면을 클릭하거나 터치하여 파문을 생성할 수 있다.
8. 다른 테마를 선택하면 기존 사운드가 자연스럽게 줄어들고 새로운 사운드가 재생된다.

사용자가 별도의 조작 없이 화면을 바라보는 것만으로도 편안함을 느낄 수 있어야 한다.

# 4. 테마별 디자인 및 콘텐츠

## 4-1. FOREST STREAM

<theme>FOREST STREAM — Forest & Stream</theme>

**Sound:** 새소리와 물소리가 함께 들리는 자연환경

**Mood:** 숲속 계곡에 앉아 물소리와 새소리를 듣는 듯한 편안함.

### Design Direction

- 숲속 계곡이나 나무 사이로 흐르는 작은 개울
- 이끼, 나뭇잎, 햇빛, 투명한 물의 질감
- 자연광이 물 표면에 반사되는 모습
- 지나치게 선명하거나 인공적인 그래픽보다 자연스럽고 부드러운 표현

### Color Palette

- Moss Green
- Sage Green
- Warm Beige
- Soft Sunlight Yellow
- Natural Water Blue

테마 색상은 자연환경 시각화 영역에 적용하며, 공통 UI 디자인 토큰은 01 문서를 따른다.

### Visual Elements

- 화면 아래쪽에 흐르는 계곡물
- 물 표면에 반사되는 햇빛
- 천천히 움직이는 나뭇잎
- 물 위에 생기는 잔잔한 물결
- 은은하게 움직이는 빛과 그림자

### Animation

- 물 표면이 천천히 흐르는 듯한 움직임
- 나뭇잎이 바람에 흔들리는 효과
- 햇빛이 물 위에서 반짝이는 효과
- 자연스러운 속도의 반복 애니메이션
- 깊이감이 느껴지는 물 표면의 움직임

### Interaction

FOREST에서는 사용자의 직접적인 조작보다 자연환경의 움직임을 바라보는 경험을 우선한다.

물결과 나뭇잎이 자연스럽게 움직이도록 하고 시각적으로 과도한 반응은 피한다.

## 4-2. FLOW — Floating Droplets

**Sound:** 물 흐르는 소리

**Mood:** 투명한 물속에 들어와 물방울을 바라보는 듯한 고요함.

### Design Direction

- 투명한 물속에 들어온 듯한 분위기
- 딥 블루, 아쿠아, 청록색 계열의 부드러운 그라데이션
- 크기가 서로 다른 투명한 물방울
- 부드러운 하이라이트와 굴절 표현
- 자연스러운 깊이감
- 과도한 네온이나 강한 광택은 지양

### Visual Elements

- 크기가 서로 다른 투명한 구형 물방울
- 물방울 내부의 은은한 빛
- 굴절된 듯한 색상 변화
- 물 표면의 잔잔한 움직임
- 깊이에 따라 다르게 움직이는 입자

### Animation

- 물방울이 각기 다른 방향으로 천천히 이동
- 좌우로 미세하게 흔들리는 움직임
- 물방울 크기가 미세하게 변화하는 효과
- 물방울마다 서로 다른 속도를 적용
- 물방울이 자연스럽게 떠다니는 깊이감
- 전체적으로 느리고 부드러운 움직임 유지

### Interaction

**FLOW는 세 가지 테마 중 사용자 인터랙션이 가장 중요한 테마다.**

- 마우스 클릭 시 해당 위치에서 파문 생성
- 모바일 터치 시 동일한 반응 구현
- 파문은 중심에서 바깥쪽으로 자연스럽게 확산
- 파문이 커지면서 점차 투명해지도록 표현
- 여러 번 클릭해도 파문이 자연스럽게 겹치도록 구현
- 과도한 그래픽 생성을 방지하기 위해 파문 개수 제한

사용자의 클릭과 터치가 물 표면에 실제로 파동을 일으키는 듯한 경험을 제공한다.

# 5. 화면 및 UI 구성

## 5-1. 메인 화면

전체 화면을 활용하는 몰입형 구조로 구성한다.

### UI 구성

1. 상단: WATER THERAPY 타이틀
2. 중앙: p5.js 기반 자연환경 시각화
3. 중앙 또는 하단: 세 가지 테마 선택 UI
4. 하단: 재생 및 음량 조절 UI

### 디자인 요구사항

- 자연환경의 시각적 몰입감을 최우선으로 한다.
- UI가 배경과 애니메이션을 지나치게 가리지 않아야 한다.
- 불필요한 설명과 장식은 최소화한다.
- 공통 UI는 01 문서의 디자인 시스템을 적용한다.
- 테마별 시각적 분위기는 서로 명확하게 구분한다.
- 모바일에서도 주요 컨트롤을 쉽게 조작할 수 있어야 한다.

## 5-2. 테마 선택 UI

| 버튼 | 사운드 | 시각적 환경 |
|---|---|---|
| FOREST | 새소리 + 물소리 | 숲속 계곡 |
| FLOW | 물 흐르는 소리 | 투명한 물방울과 파문 |
| UNDERWATER | 수중 환경음 | 깊은 바닷속 |

요구사항:

- 현재 선택된 테마를 명확하게 표시한다.
- 버튼 선택 시 시각적 테마가 변경된다.
- 사운드와 시각적 상태가 일치해야 한다.
- 선택 UI는 HTML/CSS로 구현한다.
- 모바일에서도 쉽게 조작할 수 있어야 한다.
- 선택 상태를 색상만으로 구분하지 않는다.

## 5-3. 오디오 컨트롤

필수 컨트롤:

- 재생 버튼
- 일시정지 버튼
- 음량 조절 슬라이더
- 현재 선택된 테마 표시

요구사항:

- 재생과 일시정지를 구분한다.
- 현재 재생 중인 상태를 시각적으로 표시한다.
- 음량을 0~100 범위에서 조절한다.
- 음량 0에서도 재생 상태와 일시정지 상태를 구분한다.
- 테마 전환 후에도 설정한 음량을 유지한다.

- 세 가지 테마의 명확한 시각적 구분
- 갑작스러운 화면 변경 방지
- 부드러운 색상 및 배경 전환
- 오디오와 시각적 테마 상태 동기화

## FR-05. 인터랙션

- FOREST: 자연스러운 물결과 나뭇잎 움직임

- UNDERWATER: 기포와 입자 움직임

## FR-06. 음량 조절

- 0~100 범위
- 전체 음량 조절
- 테마 전환 후 음량 유지
- 음량 0에서 소리 출력 방지

## FR-07. 반응형

- 데스크톱, 태블릿, 모바일 지원
- 캔버스 크기 자동 조정
- 그래픽 배치 자동 조정
- 마우스 및 터치 이벤트 지원
- 360px 너비에서도 콘텐츠가 잘리지 않도록 구현

## FR-08. 오류 처리

- MP3 파일 로드 실패 확인
- 사운드 재생 실패 처리
- 사용자에게 현재 상태를 간결하게 안내
- 오류가 발생해도 시각화 기능은 가능한 범위에서 유지

## FR-09. 접근성

01 문서의 접근성 규칙을 준수한다.

특히 다음 항목을 확인한다.

- 키보드 탐색
- 명확한 포커스 표시
- 버튼 접근성 이름
- 충분한 텍스트 대비
- reduced-motion 지원
- 최소 44px 조작 영역

# 7. p5.js 시각화 구현 구조

## 7-1. 인스턴스 모드

p5.js 인스턴스 모드로 구현한다.

```javascript
const waterTherapySketch = (p) => {

  let currentScene = 'forest';

  p.setup = () => {
    p.createCanvas(
      p.windowWidth,
      p.windowHeight,
      p.P2D
    );

    p.pixelDensity(
      Math.min(p.displayDensity(), 2)
    );
  };

  p.draw = () => {

    switch (currentScene) {

      case 'forest':
        drawForest(p);
        break;

      case 'flow':
        drawFlow(p);
        break;

      case 'underwater':
        drawUnderwater(p);
        break;

    }

  };

  p.windowResized = () => {
    p.resizeCanvas(
      p.windowWidth,
      p.windowHeight
    );
  };

};

new p5(
  waterTherapySketch,
  'water-therapy-canvas'
);
```

위 코드는 구조 예시이며 실제 프로젝트의 레이아웃과 컨테이너 크기에 맞춰 조정한다.

## 7-2. 테마별 렌더링 함수

```javascript
function drawForest(p) {
  // 숲과 계곡
}

function drawFlow(p) {
  // 물방울과 파문
}

```

각 함수는 자신의 테마에 해당하는 시각적 요소만 렌더링한다.

- reduced-motion 설정 반영
- 애니메이션이 필요하지 않은 상황에서 불필요한 렌더링 방지

# 8. 오디오 파일 및 관리

## 8-1. 기본 파일 경로

반드시 다음 경로를 기준으로 확인한다.

```text
assets/sound/forest.mp3
assets/sound/flow.mp3
assets/sound/underwater.mp3
```

**주의: 폴더명은 `sound`이며 `sounds`가 아니다.**

## 8-2. 오디오 연결

| 테마 | 기본 경로 |
|---|---|
| FOREST | assets/sound/forest.mp3 |
| FLOW | assets/sound/flow.mp3 |
| UNDERWATER | assets/sound/underwater.mp3 |

실제 파일명이 다르면 프로젝트 내부 파일을 확인하고 정확한 이름으로 연결한다.

파일이 없으면 임의의 파일명을 만들어 연결하지 않는다.

## 8-3. 오디오 상태 관리

기본 상태 예시:

```javascript
const audioState = {
  currentScene: 'forest',
  isPlaying: false,
  volume: 70,
  isTransitioning: false
};
```

오디오 관리는 시각화 로직과 분리한다.

필요한 기능:

- 사운드 로딩
- 재생
- 일시정지
- 반복 재생
- 전체 음량 조절
- Crossfade
- 중복 재생 방지
- 오류 처리

테마 전환 중 새로운 테마가 다시 선택되는 경우 마지막 선택 상태가 정상적으로 반영되어야 한다.

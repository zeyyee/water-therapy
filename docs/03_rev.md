# 1. PROJECT OVERVIEW

## 1.1 프로젝트 소개

물멍은 사용자가 잔잔한 물 표면을 바라보며 휴식을 취할 수 있는 인터랙티브 웹 테라피 공간이다.

단순히 물소리를 재생하거나 물 영상을 보여주는 것이 아니라, 사용자의 마우스 움직임과 클릭에 반응하여 물결이 자연스럽게 퍼지는 경험을 제공한다.

사용자는 마우스를 움직이거나 클릭하면서 물 표면에 잔물결을 만들 수 있으며, 아무런 행동을 하지 않을 때는 화면이 다시 고요해진다.

물소리는 총 3가지 중 취향에 따라 선택할 수 있으며, 시각적 디자인은 하나의 통일된 물 표면을 유지한다.

## 1.2 핵심 콘셉트

**"손끝이 닿을 때마다 물결이 번지는 디지털 물멍 공간"**

사용자의 행동에 반응하지만 사용자를 재촉하지 않는 공간을 지향한다.

- 시각적으로 편안하고 잔잔한 분위기
- 자연스럽고 부드러운 물결 애니메이션
- 마우스 움직임에 반응하는 인터랙션
- 취향에 따라 선택할 수 있는 3가지 물소리
- 불필요한 UI를 최소화한 몰입형 화면

## 1.3 디자인 키워드

`Minimal` `Ambient` `Fluid` `Immersive` `Calm`

# 2. DESIGN DIRECTION

## 2.1 전체 디자인 방향

기존 WATER THERAPY 웹사이트의 디자인 시스템을 그대로 계승한다.

특히 비멍 페이지를 주요 UI 및 레이아웃 레퍼런스로 활용한다.

물멍을 별개의 독립적인 웹사이트처럼 제작하지 않는다.

기존 사이트의 브랜드 정체성, 레이아웃, 타이포그래피, 여백, 버튼 스타일 및 UI 구성 방식을 유지하면서 물멍만의 시각적 경험을 구현한다.

**핵심 방향**

- 비멍과 동일한 공통 레이아웃
- 비멍과 동일한 헤더 및 네비게이션 구조
- 비멍과 동일한 콘텐츠 배치 방식
- 비멍과 동일한 버튼 및 컨트롤 스타일
- 물멍만의 독립적인 시각적 인터랙션

## 2.2 컬러 시스템

물멍은 어둡고 차분한 딥 틸(Deep Teal) 계열을 중심으로 구성한다.

| 요소 | 컬러 | HEX |
|---|---|---|
| Background | Deep Navy | #071C28 |
| Water Base | Dark Teal | #103D46 |
| Water Highlight | Muted Cyan | #65B9B5 |
| Light Reflection | Soft White | #E5F0ED |
| Secondary Text | Muted Gray | #A6C4C1 |

실제 색상은 기존 사이트의 컬러 시스템과 조화를 이루도록 조정한다.

## 2.3 물 표면 디자인

화면의 메인 영역은 하나의 연속된 물 표면으로 구성한다.

**시각적 특징**

- 어두운 청록색 계열의 수면
- 은은한 빛 반사
- 자연스럽고 부드러운 수면 움직임
- 과도한 대비나 밝은 발광 효과 지양
- 원형 물결이 자연스럽게 퍼지는 형태
- 실제 물 표면을 연상시키는 유기적인 움직임

물 표면을 여러 개의 카드나 독립적인 이미지로 분할하지 않는다.

화면 전체가 하나의 연속적인 수면처럼 느껴져야 한다.

# 4. AUDIO SYSTEM

## 4.1 오디오 구성

물소리는 총 3가지를 제공한다.

| ID | Audio Name | Sound Concept |
|---|---|---|
| lake.mp3 | 잔잔한 호수 | 잔잔한 물결과 고요한 수면 |
| river.mp3 | 졸졸 흐르는 물 | 맑고 부드러운 시냇물 |
| ocean.mp3 | 파도 소리 | 해변가에 부딪히는 잔잔한 파도 |

실제 오디오 파일은 기존 프로젝트의 assets/sound/ 경로에 저장된 파일을 사용한다.

파일명은 실제 프로젝트의 에셋을 확인한 후 매핑한다.

임의로 파일을 생성하거나 존재하지 않는 파일 경로를 지정하지 않는다.

## 4.2 오디오 동작

- 사용자가 원하는 물소리를 선택할 수 있어야 한다.
- 한 번에 하나의 소리만 재생한다.
- 소리 변경 시 기존 소리를 자연스럽게 페이드아웃하고 새로운 소리를 페이드인한다.
- 재생 및 일시정지가 가능해야 한다.
- 볼륨 조절이 가능해야 한다.
- 음소거 기능을 제공한다.
- 브라우저의 자동재생 제한을 고려하여 사용자 입력 후 재생한다.

## 4.3 UI 동작

기존 비멍의 오디오 선택 UI를 참고한다.

선택된 오디오는 기존 사이트의 활성 버튼 스타일로 구분한다.

소리 선택에 따라 물 표면의 색상이나 애니메이션이 변경되어서는 안 된다.

**세 가지 소리는 오디오만 다르고 시각적 공간은 동일하다.**

# 5. INTERACTION DESIGN

## 5.1 Mouse Interaction

### A. Mouse Move

사용자가 마우스를 움직이면 마우스가 지나간 위치에 잔물결이 생성된다.

- 마우스 위치를 추적한다.
- 이전 마우스 좌표와 현재 좌표를 비교한다.
- 이동 경로를 따라 자연스러운 작은 물결을 생성한다.
- 빠른 마우스 이동에도 물결이 지나치게 많이 생성되지 않도록 제한한다.
- 물결이 서로 겹치면서 자연스러운 수면을 연출한다.

### B. Mouse Click

사용자가 물 표면을 클릭하면 해당 위치에서 원형 물결이 퍼져나간다.

- 클릭 위치를 중심으로 원형 파동 생성
- 시간이 지날수록 반지름 증가
- 점점 투명해지면서 사라짐
- 여러 번 클릭하면 여러 물결이 동시에 존재 가능
- 물결의 크기와 속도는 자연스럽고 부드럽게 설정

### C. Mouse Drag

마우스를 누른 상태로 움직이면 연속적인 물결이 생성된다.

- 마우스 이동 경로를 따라 잔물결 생성
- 물결이 부드럽게 이어지는 느낌
- 개별 물결이 과도하게 겹치지 않도록 제한
- 드래그를 멈추면 새로운 물결 생성 중단

### D. Idle State

사용자가 마우스를 움직이지 않으면 화면이 다시 고요해진다.

- 기존 물결은 천천히 사라진다.
- 기본 수면 애니메이션은 아주 약하게 유지한다.
- 일정한 간격으로 약한 자연 파동이 발생할 수 있다.
- 화면이 완전히 정지된 것처럼 보이지 않도록 한다.

## 5.2 Interaction Controls

기존 비멍의 컨트롤 UI 스타일을 유지한다.

### 움직임 멈추기

- 물 표면의 애니메이션을 정지한다.
- 다시 누르면 애니메이션을 재개한다.
- 버튼 상태에 따라 텍스트 또는 아이콘을 변경한다.

### 물소리 켜기

- 오디오 재생 및 일시정지 기능을 제공한다.
- 현재 재생 상태를 시각적으로 표시한다.

### Volume Control

- 슬라이더로 볼륨을 조절한다.
- 음량을 실시간으로 반영한다.
- 음소거 상태도 지원한다.

# 6. VISUAL EFFECTS

## 6.1 Ripple Effect

물멍의 핵심 시각 효과다.

원형 파동이 물 표면에 퍼지는 형태를 구현한다.

**요구사항**

- 원형 파동의 반지름 증가
- 투명도 감소
- 부드러운 애니메이션
- 자연스러운 물결 중첩
- 파동이 사라질 때 갑자기 끊기지 않도록 처리

## 6.2 Water Distortion

단순한 원형 선만 표현하는 것이 아니라 실제 수면이 움직이는 듯한 왜곡 효과를 추가한다.

마우스가 움직인 주변의 물 표면이 살짝 밀리고 휘어지는 느낌을 구현한다.

가능하다면 WebGL Shader를 활용하여 수면 왜곡 및 빛의 굴절 효과를 표현한다.

다만 구현 복잡도가 지나치게 높아지는 경우에는 p5.js의 기본 도형과 노이즈 기반 애니메이션을 활용한 대체 방식을 사용한다.

**우선순위**

1. 자연스러운 원형 물결
2. 마우스 반응
3. 부드러운 수면 움직임
4. 수면 왜곡 및 빛 반사 고도화

## 6.3 Animation Quality

- 움직임은 전체적으로 느리고 차분해야 한다.
- 물결이 지나치게 빠르게 퍼지지 않아야 한다.
- 과도한 번쩍임과 발광 효과를 사용하지 않는다.
- 물결이 화면을 가득 채울 정도로 복잡해지지 않도록 한다.
- 인터랙션이 없을 때에도 기본적인 수면 움직임은 유지한다.

# 7. TECHNICAL REQUIREMENTS

## 7.1 Development Environment

- p5.js
- p5.sound
- HTML
- CSS
- JavaScript

기존 프로젝트의 기술 스택과 라이브러리 버전을 유지한다.

새로운 라이브러리 설치는 반드시 필요한 경우에만 검토한다.

## 7.2 Suggested Implementation

### Ripple Object

물결을 개별 객체로 관리한다.

객체에 포함할 데이터 예시:

- x: 물결 중심의 X 좌표
- y: 물결 중심의 Y 좌표
- radius: 현재 반지름
- alpha: 현재 투명도
- speed: 확산 속도
- maxRadius: 최대 반지름

### Ripple Array

생성된 물결을 배열로 관리한다.

- 마우스 클릭 및 이동으로 물결 추가
- draw()에서 각 물결 업데이트
- 투명도가 0에 가까워지면 배열에서 제거
- 물결 개수가 지나치게 많아지지 않도록 제한

### Mouse Events

다음 이벤트를 활용한다.

- mouseMoved()
- mousePressed()
- mouseDragged()

마우스 이벤트는 물 표면 영역 내부에서만 반응하도록 처리한다.

## 7.3 Responsive Design

PC와 모바일 환경을 모두 지원한다.

**Desktop**
- 마우스 이동 및 클릭 지원
- 드래그 인터랙션 지원
- 넓은 물 표면 영역 제공

**Mobile**
- 터치 위치에 따른 물결 생성
- 드래그에 따른 연속 물결 생성
- 기존 UI의 반응형 구조 유지
- 오디오 선택 및 볼륨 조절 가능

## 7.4 Performance

- 불필요한 객체 생성 최소화
- 화면에서 사라진 물결 객체 제거
- 과도한 물결 생성 제한
- 애니메이션 프레임 저하 방지
- 모바일에서도 원활하게 작동하도록 최적화

# 8. UX REQUIREMENTS

물멍은 사용자가 기능을 학습해야 하는 서비스가 아니라 직관적으로 사용할 수 있는 휴식 공간이어야 한다.

따라서 UI를 최소화한다.

**필수 UX 원칙**

1. 처음 접속했을 때 물 표면이 자연스럽게 보여야 한다.
2. 마우스를 움직이면 별도의 설명 없이도 반응을 확인할 수 있어야 한다.
3. 오디오 선택이 직관적이어야 한다.
4. 소리 전환이 갑작스럽지 않아야 한다.
5. 모든 컨트롤은 기존 비멍과 일관된 디자인을 유지해야 한다.
6. 물결이 과도하게 발생해 시각적 피로를 유발하지 않아야 한다.

# 10. DESIGN RESTRICTIONS

다음 사항을 반드시 준수한다.

- 비멍 페이지와 다른 레이아웃을 임의로 제작하지 않는다.
- 기존 공통 헤더와 네비게이션을 중복 구현하지 않는다.
- 물소리 선택에 따라 시각적 테마를 변경하지 않는다.
- 별도의 물 이미지나 영상으로 메인 화면을 대체하지 않는다.
- 과도한 버튼과 설명 문구를 추가하지 않는다.
- 지나치게 밝거나 화려한 네온 효과를 사용하지 않는다.
- 물결이 기계적으로 반복되는 느낌을 주지 않도록 한다.
- 기존 다른 테라피 페이지의 코드를 임의로 수정하지 않는다.
- 기존 오디오 파일 및 에셋을 임의로 삭제하거나 변경하지 않는다.

# 11. ACCEPTANCE CRITERIA

개발 완료 후 다음 항목을 확인한다.

- [ ] 비멍과 동일한 공통 레이아웃이 적용되어 있다.
- [ ] 기존 사이트의 디자인 시스템과 일관성이 있다.
- [ ] 딥 틸 계열의 통일된 물 표면이 구현되어 있다.
- [ ] 기본 수면 애니메이션이 자연스럽게 작동한다.
- [ ] 마우스 클릭 시 원형 물결이 퍼진다.
- [ ] 마우스 이동 시 잔물결이 생성된다.
- [ ] 마우스 드래그 시 연속적인 물결이 생성된다.
- [ ] 물결이 시간이 지나면 자연스럽게 사라진다.
- [ ] 물소리 3종을 선택할 수 있다.
- [ ] 소리 전환 시 자연스러운 페이드 효과가 적용된다.
- [ ] 재생 및 일시정지 기능이 작동한다.
- [ ] 볼륨 조절 및 음소거가 작동한다.
- [ ] 움직임 멈추기 기능이 작동한다.
- [ ] 모바일 터치 인터랙션이 지원된다.
- [ ] 기존 다른 페이지에 영향을 주지 않는다.

# 12. FINAL EXPERIENCE

물멍은 사용자가 물을 바라보고, 손끝으로 건드리고, 다시 고요해지는 과정을 경험하는 디지털 테라피 공간이다.

비멍이 창문에 맺힌 빗방울을 통해 휴식을 제공한다면, 물멍은 잔잔한 수면에 퍼지는 물결을 통해 휴식을 제공한다.

**"아무것도 하지 않아도 괜찮아요. 잠시 물결을 바라봐요."**

이것이 물멍이 전달해야 하는 핵심 경험이다.
